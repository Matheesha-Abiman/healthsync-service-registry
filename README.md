# 📡 HealthSync Service Registry

Dynamic service discovery server built with **Netflix Eureka Server**.

---

## ⚙️ Details

- **Port**: `9001`
- **Dashboard**: `http://localhost:9001`
- **Function**: Registers active microservice instances and enables load-balanced client lookups.
